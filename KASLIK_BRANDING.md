# Kaslik Kart Rush

A community fork/custom Android game based on the SuperTuxKart codebase.

- Game name: **Kaslik Kart Rush**
- Brand: **Kaslik Services**
- Developer credit: **Kaslik Noristani**
- Android application ID: `com.kaslikservices.kaslikkartrush`
- Primary Android build target: ARM64 (`arm64-v8a`)
